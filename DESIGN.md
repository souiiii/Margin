# Margin design system

The visual authority is the user's Mochi references: a quiet, light learning workspace with dark teal text, pale cool surfaces, peach marks, and confident typography. Reader mode adds a narrow reading measure and an optional annotation rail. App controls use a readable sans; headings and short language prompts use a characterful mono inspired by the references; long reading uses a book serif. This is a working app, with no marketing surface.

## Tokens
- Canvas: #f6f7f5; paper: #ffffff; sidebar: #eef1ef
- Ink: #173d42; secondary: #5d7072; hairline: #dce3df
- Accent: #287e87; accent-hover: #20656d; accent-soft: #e5f1ef
- Mark: #ffe0c8; error: #a83f37; success: #26704d
- UI: self-hosted DM Sans; headings: self-hosted DM Mono; reading: Georgia
- Spacing: 4, 8, 12, 16, 24, 32, 48, 64px
- Radius: inputs/buttons 7px, learning cards 14px
- Motion: state-driven 160ms ease-out; reduced motion supported

## Composition
220px sidebar, quiet top toolbar, generous task canvas. Today shows one next step, daily discoveries, and real recent reading. Bank is a searchable list with a detail pane. Reading keeps comprehension beneath the source. Practice shows one exercise at a time. At narrow widths navigation collapses and detail panes become full-width. Empty, loading, error and offline states are first-class.
